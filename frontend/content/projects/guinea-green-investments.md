## Overview

Guinea Green Investments is a production-grade corporate web platform built to showcase sustainable global opportunities across energy markets, natural resource concessions, and cross-border trade. The platform features structured layouts for international operations spanning Abuja, Nigeria and Houston, Texas.

## Architecture & Features

- **Modern Frontend Stack:** Engineered with Nuxt 4 and Vue 3, leveraging server-side rendering and static generation capabilities for optimal performance and SEO.
- **Responsive Corporate UI:** Styled using Tailwind CSS and NuxtUI to present core sectors including oil & gas asset delivery, mining sourcing, global commodity trading, and government relations.
- **Containerized Deployment:** Fully containerized using Docker with multi-stage builds optimized for modern hosting environments and CI/CD workflows.
